# DevOps Launchpad — CI/CD Website

## Overview
A static website focused on DevOps concepts, technical skills, pipeline stages and project highlights.

## Technologies
- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Features
- DevOps-themed landing page
- Skills and projects sections
- Responsive frontend styling
- JavaScript-based interface interactions

## Run Locally
```bash
git clone https://github.com/rakesh-cloudops/jenkins-cicd-website.git
cd jenkins-cicd-website
python3 -m http.server 8000
```

Open http://localhost:8000 in your browser.

## CI/CD Learning
This website can be extended with a Jenkins pipeline for validation and deployment. Automated deployment should only be claimed after it has been configured and tested.
