# Jenkins Pipeline Demo

## Overview
A beginner-level project for practising Jenkins jobs, GitHub source checkout and pipeline console output.

## Technologies
- Jenkins
- Git
- GitHub

## Current Project
This repository contains a sample `hello.txt` file for basic pipeline exercises.

## Getting Started
```bash
git clone https://github.com/rakesh-cloudops/jenkins-pipeline-demo.git
cd jenkins-pipeline-demo
cat hello.txt
```

## Learning Workflow
1. Create a Jenkins Pipeline job.
2. Configure the Git repository.
3. Check out the source code.
4. Display `hello.txt` in the build log.
5. Review the build result.

A Jenkinsfile can be added to automate these steps. Verify the original repository before assuming a pipeline is already configured.
