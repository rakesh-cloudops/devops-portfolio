# Java Web Application — Maven & Tomcat

## Overview
A Java 17 JSP web application packaged as a WAR file using Maven. The application presents a sample barber shop website called Royal Cuts.

## Technologies
- Java 17
- JSP, HTML and CSS
- Apache Maven
- Apache Tomcat
- Jenkins concepts

## Key Features
- Barber shop landing page
- Services and pricing display
- Appointment form interface
- Maven WAR packaging

## Build
```bash
git clone https://github.com/rakesh-cloudops/jenkins-maven-tomcat-demo.git
cd jenkins-maven-tomcat-demo
mvn clean package
```

The generated WAR file can be deployed to a compatible Tomcat server. Confirm the artifact name in pom.xml.

## Learning Outcomes
- Maven build lifecycle
- WAR packaging
- Java web application deployment
- CI/CD workflow fundamentals
